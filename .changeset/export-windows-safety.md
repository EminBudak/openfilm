Exports are safer on Windows and when something goes wrong: a file is written under a hidden name until it is whole and then renamed, so a stop or a crash never leaves a broken file that looks made; a rename that a virus scanner or the editor watching the folder holds for a moment is tried again; cleaning up after an export that is made never fails it (it used to delete the finished files); a cancel ends the export's whole process tree; a long page's PNG keeps its pictures however many there are; the graphics chip running out of memory or sessions falls back to the processor's encoder; names ending in a dot or a space, or named like a Windows device, are written so Windows can open them; and a draft's files are named with the system's own separators.
