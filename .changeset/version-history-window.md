Version history is redesigned, in a window the size of Export.

- Versions are listed by day, with search and a filter by type (manual, auto-saved, restore, other) or named versions only. Current edits are at the top, with the files changed since the last saved version, and Save version (an optional name) when something changed.
- Selecting a version plays its film from the saved copy and lists the files it changed. Looking at a version never touches your current edits.
- Restore this version brings the project back to it. Unsaved edits are saved as a version first, so nothing is lost. Markers, settings and subtitles follow the restored version in every window. Save as new project starts a separate project from any version.
- Delete moves one or more versions to Deleted, where they can be recovered. The version in use can't be deleted, and no file or saved copy is removed.
- Discard all changes returns the film to the last saved version; files added since go to the Trash.
- A version keeps all of the project's files (pages, code, data, fonts, notes), not only the ones the film names. Unused video, sound and pictures, and files over 50 MB, are still left out. An older history is brought up to date the first time it opens.
- Settings › Advanced › Versions › Auto versions (off by default) saves a version before and after an agent's turn and when the film rests for two minutes, only when the film changed.
- Branches and merging are gone from the window; versions saved on earlier branches stay in the list.
- When the history can't be read, it says so, with Try again.
